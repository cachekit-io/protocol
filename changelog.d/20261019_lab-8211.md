### Feature matrix — Python binds the backend key prefix into the AAD from `cachekit` 0.23.0 (LAB-8211)

- The **AAD v0x03 (cache_key binding)** row marks Python ✅ again, with the floor `0.23.0+`.
  From that release the AAD `cache_key` is the
  [logical backend key](spec/encryption.md#additional-authenticated-data-aad), so a prefixing
  backend's key prefix (`MemcachedBackend` `key_prefix`, the tenant-scoped Redis backend's
  `t:{tenant}:`) is bound ([cachekit-py#518](https://github.com/cachekit-io/cachekit-py/pull/518)).
- The **Compliance Status** table's AAD v0x03 cell for Python reads ✅ Compliant `0.23.0+`. The
  post-decryption container fixes it also listed as unreleased
  ([cachekit-py#517](https://github.com/cachekit-io/cachekit-py/pull/517),
  [cachekit-py#521](https://github.com/cachekit-io/cachekit-py/pull/521)) ship in the same
  release; the cell keeps the earlier releases' gaps as history, and the Encryption note now
  cites the release instead of `main`.
- Verified against the published 0.23.0 and 0.24.0 wheels on 2026-10-19: the three PRs' tests
  pass, and the key-prefix tests fail against 0.22.0.
