### Tooling — stdlib python-frame verify: a malformed `arrow_detection` FAILs (LAB-5929)

- `tools/python-frame-reference.py verify` checks `arrow_detection` whenever the key is
  present. Before, a present `null`, `{}` or `[]` skipped both Arrow checks and verified
  green, and a non-empty list, an object missing a field, or a field of the wrong JSON type
  raised a traceback. Each now prints one `FAIL` line naming the problem: the value must
  be an object with `checksum_len` and `ipc_magic_offset` as non-negative integers and
  `checksum_hex` and `ipc_magic` as ASCII strings. An absent key is still allowed.
- The `payload_envelope` checks moved into one helper that returns the failure reason.
  Every existing `FAIL` message is unchanged.
- Only the stdlib leg changed. `tools/frame-crosscheck.mjs` (Node) still skips an empty
  `arrow_detection`.
- `test-vectors/python-frame.json` is unchanged.
