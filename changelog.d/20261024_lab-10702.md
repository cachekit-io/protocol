### SDK feature matrix — release markers brought up to cachekit-py 0.23.0 and cachekit-rs 0.11.0

- [`sdk-feature-matrix.md`](sdk-feature-matrix.md): sixteen markers that called a shipped
  PR unreleased now name the first release that carries it, checked against each SDK's
  release tags and the registries (PyPI `cachekit` 0.24.1, crates.io `cachekit-rs` 0.11.1).
- Python, since 0.23.0: the File backend's `expired_entry` read
  ([cachekit-py#514](https://github.com/cachekit-io/cachekit-py/pull/514)), the
  `temporal_sentinel_vectors` in CI
  ([cachekit-py#550](https://github.com/cachekit-io/cachekit-py/pull/550)) and the SaaS API
  `X-TTL` and fractional-TTL fixes
  ([cachekit-py#520](https://github.com/cachekit-io/cachekit-py/pull/520)). Since 0.21.0: the
  empty-key rejection ([cachekit-py#397](https://github.com/cachekit-io/cachekit-py/pull/397)),
  so the cache-key path encoding cell no longer says "on `main`, unreleased".
- Rust, since 0.11.0: the SWR refresh that never waits on another worker's fill (footnote 10,
  [cachekit-rs#147](https://github.com/cachekit-io/cachekit-rs/pull/147)), the sub-second
  `refresh_ttl` fix ([cachekit-rs#142](https://github.com/cachekit-io/cachekit-rs/pull/142)),
  auto mode rejecting a CK frame's trailing bytes (footnote 15,
  [cachekit-rs#140](https://github.com/cachekit-io/cachekit-rs/pull/140)), and the test vectors
  vendored in [cachekit-rs#146](https://github.com/cachekit-io/cachekit-rs/pull/146),
  [#150](https://github.com/cachekit-io/cachekit-rs/pull/150),
  [#152](https://github.com/cachekit-io/cachekit-rs/pull/152),
  [#158](https://github.com/cachekit-io/cachekit-rs/pull/158) and
  [#160](https://github.com/cachekit-io/cachekit-rs/pull/160) (the "Test vectors in CI" Rust
  cell and footnote 16). Footnote 16's four "py since …, ts since …" notes add
  "rs since 0.11.0".
- The TypeScript "Test vectors in CI" cell and footnote 16 no longer say cachekit-rs and
  cachekit-ts vendor the current `python-frame.json`: both vendor the
  [protocol#180](https://github.com/cachekit-io/protocol/pull/180) revision, without the
  `padded_header_frame` vector that [protocol#193](https://github.com/cachekit-io/protocol/pull/193)
  added.
- Unchanged: the markers naming
  [cachekit-py#618](https://github.com/cachekit-io/cachekit-py/pull/618) and
  [#627](https://github.com/cachekit-io/cachekit-py/pull/627), which no cachekit-py release
  carries yet, and the TypeScript markers naming
  [cachekit-ts#240](https://github.com/cachekit-io/cachekit-ts/pull/240) and
  [#245](https://github.com/cachekit-io/cachekit-ts/pull/245), which wait on an npm release
  whose bindings embed `cachekit-core` 0.7.0.
