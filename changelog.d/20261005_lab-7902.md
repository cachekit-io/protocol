### Feature matrix — Python cross-instance L1 invalidation and the CachekitIO write retry ship in `cachekit` 0.22.0

- The Python cell of **Cross-instance L1 invalidation (pub/sub)** moves from 🚧 unreleased to
  ✅ 0.22.0+: the PyPI 0.22.0 wheel carries `cachekit/invalidation.py` and the
  `invalidation_listener_enabled` setting (inspected 2026-10-05). Note ⁹ now dates the re-add
  to 0.22.0.
- The Python cell of **Retry (backoff + jitter)** stays ⚠️ (still no generic backend-op
  retry), but its CachekitIO write retry on a short `503`
  ([cachekit-py#477](https://github.com/cachekit-io/cachekit-py/pull/477)) is no longer
  unreleased: it ships from 0.22.0. Note ⁷ also records the second retry 0.22.0 ships:
  whole-function invalidation waits out a `DELETE` rate-limited with `429` + `Retry-After`
  ([cachekit-py#478](https://github.com/cachekit-io/cachekit-py/pull/478)). Its old "any
  other status is not retried" is false for 0.22.0.
