### Feature matrix — Python namespace charset cell corrected; SDK citations name symbols (LAB-8054)

- The **Namespace semantics** table's Python charset cell said only the `func:` segment is
  sanitized. In fact `CacheKeyGenerator._normalize_key` rewrites space, LF and CR to `_`
  across the whole key, namespace included, and replaces a key over 250 characters with a
  50-character prefix plus a 32-hex Blake2b-256 suffix. The cell now says so.
- Every citation into an SDK or `cachekit-core` source file now names a file and a symbol
  instead of a line number, so later SDK edits no longer silently re-point them. Checked
  against `main` of cachekit-py `f38fd551`, cachekit-ts `fce2e9b9`, cachekit-rs `ef2b26c0`
  and cachekit-core `f2bf638c`.
