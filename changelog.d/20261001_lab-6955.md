### Tooling — stdlib python-frame verify FAILs frame headers past CPython's JSON limits (LAB-6955)

- `tools/python-frame-reference.py verify` FAILs a frame whose header holds an integer
  longer than the interpreter's integer-digit limit (`sys.get_int_max_str_digits()`), or
  nests deeper than its JSON decoder accepts, as
  `FAIL <name>: parse error: header exceeds this interpreter's JSON limits: …`. It
  previously raised a traceback instead of reporting the vector, and an error vector
  carrying such a header crashed verify rather than counting as rejected. These headers
  are valid JSON, but the Python SDK's reader cannot parse them either, so verify does not
  vouch for them.
- `tools/frame-crosscheck.mjs` (Node) is unchanged.
- `test-vectors/python-frame.json` is unchanged.
