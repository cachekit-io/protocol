### Tooling — decode-bounds verify pins accept-side floor coverage and three more near-miss guards (LAB-7503)

- `tools/decode-bounds-reference.py verify` now fails unless the accept set holds one
  array spine and one map spine nested exactly `MIN_DEPTH_FLOOR` (32) deep. Before, an
  empty `accept_vectors` list, or both floor vectors rebuilt shallower, verified green, so
  a depth bound tighter than the floor went uncaught.
- `walk()` models three more mis-counting guards: a map pair counted as one slot, ext
  lengths not counted, and str/bin lengths not counted. `verify` requires a reject vector
  each one passes (`fixmap_short_by_one`, `ext32_overclaim`, and `bin32_overclaim` /
  `str32_overclaim`), with a negative control per model. Dropping any of those vectors from
  the file now fails both legs.
- `tools/test_decode_bounds_reference.py` adds a flag-table row per model boundary, a drop
  row per new coverage check, accept-side twins, and an always-true control per new model.
- `test-vectors/decode-bounds.json` is unchanged.
