### Tooling — stdlib python-frame verify rejects NaN/Infinity in frame headers (LAB-6920)

- `tools/python-frame-reference.py verify` FAILs a frame whose header bytes hold the
  non-standard JSON tokens `NaN`, `Infinity` or `-Infinity`, as
  `FAIL <name>: parse error: …`. RFC 8259 JSON has no such tokens, but Python's `json`
  accepts them. verify compares headers as canonical JSON, and `json.dumps` writes these
  values back out as `NaN` / `Infinity`, so a header and an `expected_header` holding the
  same token compared equal and the vector passed.
- `tools/frame-crosscheck.mjs` (Node) is unchanged: its `JSON.parse` already rejects
  these tokens.
- `test-vectors/python-frame.json` is unchanged.
