### Interop mode — decode-bounds conformance names the guard behind a size cap; reference tool hardened (LAB-5843)

- [`spec/interop-mode.md` → Decode bounds](spec/interop-mode.md#decode-bounds): where
  a size cap rejects a reject vector before the structural guard sees it, the SDK's
  conformance test MUST also call that entry point's structural guard directly with
  the vector. A cap alone no longer stands in for the guard behind it.
- [`tools/decode-bounds-reference.py`](tools/decode-bounds-reference.py) `verify`
  now fails a reject vector with an empty `reject_reasons` on the stdlib-only leg too,
  and `walk()` drops an unreachable early exit. Its mutation suite adds a walk row for
  every remaining fixed-width type and an array-inside-map row, and pins each coverage
  check's refinements with a near-twin vector. `test-vectors/decode-bounds.json` is
  unchanged (`1.1.0`).
