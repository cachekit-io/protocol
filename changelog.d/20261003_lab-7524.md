### Feature matrix — cachekit-ts asserts the event entry point's structural guard (LAB-7524)

- [Feature matrix](sdk-feature-matrix.md#protocol-compliance) Test vectors in CI row:
  for the three [`decode-bounds.json`](test-vectors/decode-bounds.json) reject vectors

  calls the event entry point's structural guard directly and asserts its rejection, as
  [Decode bounds](spec/interop-mode.md#decode-bounds) requires where a size cap rejects
  first ([cachekit-ts#182](https://github.com/cachekit-io/cachekit-ts/pull/182),
  unreleased). TypeScript remains ⚠️ only for the envelope entry point (see the Wire
  format row).
