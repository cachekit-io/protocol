### Feature matrix — Python's server-bounded L1 backfill is ✅ from `cachekit` 0.22.0 (LAB-8063)

- The Python cell of the **Server-bounded L1 backfill** row moves from ⚠️ `cachekit` 0.19.0+
  to ✅ `cachekit` 0.22.0+. From 0.22.0, `X-CacheKit-Fresh-For` is parsed with the
  [Remaining Freshness](spec/saas-api.md#remaining-freshness) grammar, so a sign, `_`
  separators, whitespace, non-ASCII digits, more than seven digits or a value over the cap
  counts as `0` ([cachekit-py#504](https://github.com/cachekit-io/cachekit-py/pull/504)).
- 0.19.0–0.21.0 bound the backfill the same way but parse the value with Python's `int()`,
  so those malformed values bound it instead of counting as `0`.
