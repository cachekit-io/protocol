### Interop v2 — a vector that fails a 32-bit ratio product (LAB-2718)

- [`test-vectors/interop-v2.json`](test-vectors/interop-v2.json) **1.1.0** adds
  `constructed_container_vectors` and one vector in it,
  `lz4_ratio_product_wraps_32_bits`: a `method 1` container with a 4,294,968 B
  payload and an `original_size` of 8,523,079 B (4,278,189 B before 1.3.0),
  which readers MUST accept.
  At that payload length the ratio product overflows unsigned 32 bits (signed
  32-bit overflows from 2,147,484 B). A reader that multiplies in 32 bits, signed
  or unsigned, computes a bound of 704 B and rejects the entry. Until now every
  interop-v2 vector was under 300 B, and such a reader passed all of them. The
  ≥ 64-bit rule is now testable, not just stated.
- An implementation that supports a 32-bit target (such as `wasm32`; item 7
  defines the term) MUST pass the vector on each such target. This clause is appended to the existing
  item 7 of the conformance checklist. A pointer-width product is exact on a
  64-bit host, so a pass there proves nothing about the 32-bit target.
- The container is 4.3 MB, so the file describes it as repeated byte segments
  instead of hex. See
  [`spec/interop-v2.md` → Test Vectors](spec/interop-v2.md#test-vectors) for the
  format, and
  [Security Limits](spec/interop-v2.md#security-limits-decompression-bounds) for
  why the vector is a real accept container rather than a sizes-only row.
- **New CI guard**:
  [`tools/test_interop_v2_reference.py`](tools/test_interop_v2_reference.py)
  swaps the reference reader's ratio product for three 32-bit versions (unsigned
  wrap, signed wrap, reject on overflow). Each one passes every hex-pinned vector
  and fails the new one. The reference self-check fails if the vector is dropped,
  replaced by a `method 0` container of the same size, or declares a
  `payload_len` that disagrees with its bytes.
- [`tools/interop-v2-crosscheck.mjs`](tools/interop-v2-crosscheck.mjs) reads the
  new group. It fails when no `method 1` vector in the group fails a 32-bit
  reader, measured from the parsed bytes.
  [`tools/test-interop-v2-crosscheck-guard.mjs`](tools/test-interop-v2-crosscheck-guard.mjs)
  shows that check fails on a dropped group, an empty group, and a `method 0`
  container of the same size.
- `spec/wire-format.md` now says that `wire-format.json` has no vector for this
  rule. The ByteStorage envelope is not covered by this change.
- No SDK vendors `interop-v2.json`, so nothing downstream needs re-vendoring.
