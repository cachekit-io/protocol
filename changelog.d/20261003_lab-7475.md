### Cache-key format — the `func:` segment is a Python module path only (LAB-7475)

- The Cross-SDK limitation callout in
  [`spec/cache-key-format.md` → Key Format](spec/cache-key-format.md#key-format) no longer
  describes the `func:` segment as a "Rust crate path" or "Go package path". There is no Go
  SDK, and cachekit-rs has no auto-mode key format.
- [`spec/interop-mode.md` → The Problem](spec/interop-mode.md#the-problem) drops its Go
  auto-mode key example for the same reason.
- Clarification only: no key byte, segment or derivation step changed.
