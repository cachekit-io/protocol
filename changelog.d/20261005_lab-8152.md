### Conformance — the checker rejects footnote and link reference definitions

- **Definitions** (`tools/conformance.py`): a footnote definition, or a paragraph that opens
  with a bracketed label and a colon (`[label]: …`), is now an error in an indexed spec file,
  because GitHub moves or hides their text and a backtick inside one could hide a keyword
  GitHub shows. No spec file uses either; see [conformance/README.md](conformance/README.md).
- **Exemption**: `<!-- not-a-requirement -->` must stand alone on the line before its fence,
  trailing spaces aside; a non-breaking space after it no longer exempts the fence.
