### Test vectors — cache-key vectors pin every serializer code (LAB-4388)

- [`test-vectors/cache-keys.json`](test-vectors/cache-keys.json) 1.1.0: 7 vectors that reuse
  the `single_integer` inputs and change only `serializer_type`: `serializer_default`
  (`default` → `1s`), `serializer_auto` (`auto` → `1a`), `serializer_pythonic_alias`
  (`pythonic` → `1a`), `serializer_orjson` (`orjson` → `1o`), `serializer_arrow`
  (`arrow` → `1w`), `serializer_local` (`local` → `1l`) and `serializer_custom_identity`
  (`<custom>:ArrowSerializer` → `1x2263`). Each pins a code from
  [Serializer Codes](spec/cache-key-format.md#serializer-codes), so an SDK that writes a fixed code instead of
  deriving it fails a vector. The 10 existing vectors are unchanged. Counts: 17 vectors.
- `generator` is now `cachekit-py v0.20.0`, which reproduces all 17 keys.
- [`spec/cache-key-format.md` → Test Vectors](spec/cache-key-format.md#test-vectors) and
  [`sdk-feature-matrix.md`](sdk-feature-matrix.md) footnote 16 describe the new set.
