### Conformance — the interop cross-check rejects Symbol-keyed object properties (LAB-8754)

- `tools/interop-crosscheck.mjs` rejects a plain object with an own enumerable Symbol-keyed
  property as a non-string map key ([IOP-13](spec/interop-mode.md#iop-13)), wherever it sits.
  Before, `Object.keys` skipped the Symbol key and the object encoded as if it were absent,
  which [IOP-8](spec/interop-mode.md#iop-8) forbids. A non-enumerable Symbol key is ignored,
  as a non-enumerable string key already was. The new `nonStringKeySelftest` pins both.
  Every published vector verifies with unchanged output.
- `conformance/requirements.json`: IOP-13 cites the new self-test, and its gap note no longer
  says a JavaScript object has string keys only. `conformance/coverage.md` is regenerated.
