### Feature matrix — SaaS API deviations in each SDK's CachekitIO client (LAB-8206)

- The **Compliance Status** table's SaaS API row no longer marks any SDK fully compliant.
  Each cell names the deviations from [spec/saas-api.md](spec/saas-api.md) found in its
  published artifact on 2026-10-05:
  - Python, through `cachekit` 0.22.0: a PUT also sends the legacy `X-TTL`
    ([API-44](spec/saas-api.md#api-44)); any fractional `ttl`, the window `@cache.io`
    derives from it, and a fractional `refresh_ttl` value go out unrounded, so the server
    rejects them with `400` ([API-42](spec/saas-api.md#api-42),
    [API-54](spec/saas-api.md#api-54)); `ttl=0` and a TTL over 2,592,000 are sent rather
    than rejected. The first two are fixed in
    [cachekit-py#520](https://github.com/cachekit-io/cachekit-py/pull/520), unreleased.
  - Rust, through `cachekit-rs` 0.10.0: `refresh_ttl` rejects a sub-second TTL instead of
    sending 1 ([API-42](spec/saas-api.md#api-42)), fixed in
    [cachekit-rs#142](https://github.com/cachekit-io/cachekit-rs/pull/142), unreleased; and
    a TTL over 2,592,000 is sent rather than rejected.
  - TypeScript, through npm 0.1.5: a PUT sends only `X-TTL`, unrounded, stores `ttl` 0 with
    no expiry, and sends a TTL over 2,592,000 (all fixed on `main` by
    [cachekit-ts#110](https://github.com/cachekit-io/cachekit-ts/pull/110), unreleased); and
    a `200` lock response with an absent, empty or non-string `lock_id` counts as a lease
    ([API-65](spec/saas-api.md#api-65)), fixed in
    [cachekit-ts#215](https://github.com/cachekit-io/cachekit-ts/pull/215), unreleased.
- The **Stale-while-revalidate (server stale-grace)** row marks Python ✅ from PyPI 0.14.0,
  the first published release that writes `X-CacheKit-Stale-TTL` and revalidates a stale
  read, in place of 🚧.
