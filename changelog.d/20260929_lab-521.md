### Feature matrix — Rust observability on cachekit-rs `main`, pending release (LAB-521)

- [`sdk-feature-matrix.md` § Observability](sdk-feature-matrix.md#observability), Rust
  column: Metrics, Structured logging, and SaaS telemetry headers move from ⚠️/❌ to 🚧,

  L1 on; the API rejects it with `400` for SDK keys
  ([`spec/saas-api.md` § Required Headers](spec/saas-api.md#required-headers)).
