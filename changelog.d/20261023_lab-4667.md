### Intent presets — Rust default tenant reads ✅ (LAB-4667)

- `spec/intent-presets.md` § SDK Conformance: the Rust cell of "Default `tenant_id` is `"default"`, identical for HKDF
  and AAD" flips from ❌ to ✅ from `cachekit-rs` 0.8.0. It had said `from_env()` derived under a deployment
  namespace; no published release does. `CacheKit::secure` and `CacheKit::secure_from_env` read the
  `default_tenant_interop` vector in the SDK's tests, and through 0.11.x `CacheKit::from_env()` with
  `CACHEKIT_MASTER_KEY` set falls back to `"default"` because nothing sets the namespace it reads. Verified against
  each published `.crate` from 0.8.0 to 0.11.1.
