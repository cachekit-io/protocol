### SDK feature matrix — Python wire format compliant since cachekit-py 0.25.0

- [`sdk-feature-matrix.md`](sdk-feature-matrix.md): the Python **Wire format (ByteStorage)**
  cell now opens "✅ Compliant since 0.25.0" instead of "⚠️ Compliant except the envelope
  pre-scan". PyPI `cachekit` 0.25.0 and 0.25.1 lock `cachekit-core` 0.7.2, whose
  `ByteStorage::retrieve` runs the [Retrieve Flow](spec/wire-format.md#retrieve-flow) step-2
  pre-scan. Checked by running every `wire-format.json` 1.4.0 reject vector through each
  published wheel: `reject_envelope_slots_overclaim` gets the pre-scan's own error from 0.25.0
  and 0.25.1, and the typed decode's error from 0.24.1.
- Six markers that called
  [cachekit-py#618](https://github.com/cachekit-io/cachekit-py/pull/618) or
  [#627](https://github.com/cachekit-io/cachekit-py/pull/627) unreleased now say "since 0.25.0":
  two in the Wire format cell, one in the Python "Test vectors in CI" cell and three in
  footnote 16. Both PRs are in the `v0.25.0` tag's history.
