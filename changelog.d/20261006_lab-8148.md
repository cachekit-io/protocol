### Conformance — the checker reads inline HTML, autolinks and escapes as GitHub does

- **Inline markup** (`tools/conformance.py`): within a paragraph, heading or table cell, the
  checker now reads HTML tags, comments, processing instructions, declarations and CDATA
  sections, autolinks and backslash escapes the way GitHub's renderer does, whichever opens
  first taking its whole extent. A backtick inside one of them no longer pairs with a later
  backtick to hide a keyword that GitHub shows, and a tag may span lines inside a blockquote.
  Comments follow GitHub's grammar (`<!-->` is a whole comment; `--->` closes none), and a run
  of more than 80 backticks opens no code span. No spec file's keywords change; see
  [conformance/README.md](conformance/README.md).
