### Wire format — the canonical writer emits a literals-only block below 64 bytes (LAB-7140)

- [Library Mapping](spec/wire-format.md#library-mapping) notes that cachekit-core's `ByteStorage` writes an input shorter than 64 bytes as one literals-only LZ4 block instead of calling `lz4_flex::compress()`. The block format, the envelope and the test vectors are unchanged; only the writer's compressed bytes for an input under 64 bytes on which `lz4_flex::compress()` would emit a match differ, which [Compressed-byte reproducibility](spec/wire-format.md#compressed-byte-reproducibility-per-vector-scoping) already permits.
