### Interop v2 — decode bounds run before any output allocation (LAB-6782)

- [`spec/interop-v2.md` → Reader Algorithm](spec/interop-v2.md#check-order): for each
  container, a reader MUST complete every Security Limit check before it decompresses the
  payload, and before it allocates or grows any output buffer for it, however that buffer
  is sized. Step 4 and the Security Limits intro say the same. This matches the
  [`wire-format.md` ordering rule](spec/wire-format.md#check-order). The old text required
  only that bounds run before decompression, so a reader could reserve an output buffer
  sized from `original_size` or the payload length before its checks and still conform.
- `tools/interop-v2-reference.py` already decodes in this order and is unchanged.
  interop/v2 is a draft that no SDK implements, so no conformance cell changes.
